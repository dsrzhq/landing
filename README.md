# DSRZ HQ Landing Page

Premium landing page para dsrzhq.com. Construido según VDS v2.0 y Brief de Desarrollo v3.

## Estructura

```
dsrzhq-landing/
├── index.html              # Página principal
├── colors_and_type.css     # Tokens de diseño del sistema DSRZ
├── assets/logos/           # Logotipos SVG
└── fonts/                  # Familias tipográficas self-hosted
```

## Tecnología

- HTML5 semántico
- CSS3 con variables (CSS custom properties)
- JavaScript vanilla
- Fuentes self-hosted: Space Grotesk, Inter, Source Serif 4

## Características

- Sticky navigation con transición de fondo en scroll
- 9 secciones: NAV, HERO, SIGNAL, ECOSYSTEM, VECTORS, EVIDENCE, FOUNDER FRAME, ACCESS, FOOTER
- Modal de solicitud de acceso interactivo
- Responsive: desktop → tablet → mobile
- Accesibilidad: WCAG AA mínimo
- Sem-hosted fonts para rendimiento

## Development

Abre `index.html` en tu navegador.

## Deployment

Conectado a Vercel. Los cambios en `main` se despliegan automáticamente a dsrzhq.com.
